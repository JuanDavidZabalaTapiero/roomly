# 📋 Roomly

Aplicación de reserva de salas

---

# ⚙️ Tecnologías

- DB: PostgreSQL
- Frontend: React
- Backend: FastAPI

---

# ⚛️ React

Carpeta `client`

Instalar dependencias:

```bash
npm install
```

Levantar servicio:

```bash
npm run dev
```

---

# 🐍 FastAPI

Carpeta `server`

Crear y activar entorno virtual

```bash
python -m venv .venv
.venv\Scripts\activate
```

Instalar dependencias

```bash
pip install -r requirements.txt
```
